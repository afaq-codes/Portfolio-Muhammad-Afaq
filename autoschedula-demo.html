My final-year project at the University of Education, Lahore. An admin sets up classes, sections, courses, teachers and time slots, then builds a timetable for each section. The app refuses a second entry for the same room, slot and day.

The problem

One room, booked twice.

A timetable built by hand makes it easy to put two classes in one room at the same time. AutoSchedula keeps the setup data in one place and checks each entry when it is saved.

What I built

Backend, Angular app and database.

Multi-tenant

Each institute is a tenant with its own users and data.

Roles and features

Users get roles, and roles get features, so each screen is open to the right people.

Sign-in

JWT access and refresh tokens, with emails for new accounts and forgotten passwords.

Classes and sections

Create classes and the sections inside them.

Courses, teachers, lectures

Full create, edit and delete screens for each.

Time slots and terms

Set the slots in a day and pick the term from a list.

Timetable sheets

One sheet per section: course, teacher, room, slot and day.

Clash check

Saving a second entry for the same room, slot and day is refused.

Screens

From setup to sheet.

Not built: there is no automatic timetable generator and no AI. Entries are added by hand, and the app checks each one.

In Plain Words

Every purchase creates a lot with its own cost. Every sale takes stock from the oldest lot first, then moves to the next one. Because each sale knows exactly which lots it used, profit is calculated per batch, not from one average price.

In Plain Words

A licence is a small payload signed with an Ed25519 private key. That private key never leaves the issuer. The licence is bound to a stable machine id, so it belongs to one computer. The app checks the signature offline with the public key, so no server call is needed. The shop activates once and is never asked again.
